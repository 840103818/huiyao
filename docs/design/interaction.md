# 交互规范

## 项目任务栏

- 宽屏左栏默认 272px，可在 240–336px 内调整；窄于 1240px 使用同构 Drawer。
- 顶部依次为项目切换、搜索/筛选、入队预设和真实队列进度；任务列表每次追加 50 条。
- 无选中任务时展示项目概览；选中任务后恢复视觉输入、摄影测定和提示词。
- 批量操作仅在存在选择时出现，避免常驻按钮噪声。危险操作进入 30 天废纸篓。
- `Cmd+K` 打开本地快捷命令；不向模型发送命令内容。

## 工作台分栏

- 项目栏和视觉输入/结果之间均提供可访问的纵向分隔器。
- 拖动实时预览宽度，释放后才保存；方向键微调，`Shift+方向键` 加速调整。
- 双击分隔器或按 `Home`、`Enter` 恢复默认值；保存范围由前后端共同归一化。
- 用户尺寸通过现有 `save_workspace_preferences` 命令保存，不覆盖设置页尚未提交的模型配置。
- 结果区内部横向分隔仍由摄影测定的自动/手动比例逻辑独立管理。

## 渐进呈现

默认显示图片、预设、开始队列、摄影测定摘要和提示词。EXIF、原图操作、提示词版本和诊断保持按需展开；不维护两套页面。

## 状态优先

界面主操作必须直接表达当前可执行动作：未配置模型时显示“配置模型服务”，缺图时要求导入，生成中切换为“停止生成”，历史缩略图恢复后明确提示需要原图才能重新反推。

生成阶段依次为准备图片、连接模型、等待首字、实时解析和整理结果；优化阶段依次为准备优化、连接模型、生成双语版本和整理结果。阶段来自真实状态和 SSE 事件，不显示虚假百分比。

## 流式打印反馈

- SSE 已接收内容与界面已显示内容分别维护；界面最多每 40ms 更新一次，避免每个 Token 触发 React 渲染。
- 少量积压按单字符显示，中等积压逐步加速，大量积压单帧最多追赶 48 个 Unicode 字符。请求完成后最多用 240ms 收尾，再切换到后端严格结果。
- 摄影测定只在当前增长字段显示低干扰光标；进入提示词阶段后移除测定光标。提示词光标始终跟随当前显示内容。
- 中英文页签在后台同时接收和打印，切换语言不重启请求。只有用户仍位于正文底部时才自动跟随。
- 停止或断流立即刷新已经收到的内容，不推测或补齐未收到文本；兼容模式无 SSE 增量时直接展示最终结果。
- 流式容器使用 `aria-busy`，逐字阶段关闭 `aria-live`，完成或停止后只提供稳定结果通知，避免屏幕阅读器逐字播报。
- `prefers-reduced-motion: reduce` 下关闭逐字延迟和光标闪烁，不隐藏真实状态或统计。

## 图片输入

- 空画布支持点击、拖入和粘贴；已有图片时拖入直接进入替换确认。
- 图片画布单击聚焦、双击打开查看器；放大后可拖动且受边界约束。
- 查看器使用 Portal 覆盖整个应用，打开时隐藏窗口装饰，关闭和异常卸载时恢复。
- 处理或生成期间禁止替换，并在画布内说明原因。
- 画布缩放、适应、复位和查看器入口使用轻量悬浮工具栏；原图和危险操作收进更多菜单。

## 结果阅读

- 摄影测定十项按画面、光影和成像分组，每项占完整宽度。
- 默认显示摘要，可单项、分组或全部展开；完整模型内容始终保留。
- 流式阶段冻结结果分隔，完成后仅自动测量一次；用户手动比例优先并持久化。
- 提示词正文独立滚动，只有用户位于底部时才自动跟随流式内容。
- 提示词操作栏固定底部；部分结果仅允许复制当前提示词，最终结果才允许完整复制和导出。

## 历史与诊断

- 左键恢复历史；右键只打开复制、重命名和原图导出菜单，不切换任务。
- 所有删除操作要求确认，永久删除原图需明确说明不可恢复。
- 设置存在未保存修改时，任何离开入口都经过统一确认。
- 错误在相关面板内持续显示，并提供重试、设置、关联日志和导出诊断。
- 明文 HTTP、永久删除、清空以及替换未保存结果必须使用可见的 Modal 或 Popconfirm，不以 Message 代替确认。
