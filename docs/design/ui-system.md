# 界面设计系统

1.0 采用 Apple 原生极简的 macOS 数字暗房工作台：图片和结果优先，使用纯中性灰与石墨表面，紫色仅用于主操作与选中，绿色只表示成功或在线。面板圆角不超过 8px，不使用渐变、装饰网格或高强度霓虹。

项目任务栏、项目概览、视觉输入与结果区共享 8/12/16/24px 间距体系、32–36px 控件、42–44px 面板标题栏、焦点环、禁用态和 120–180ms 过渡。队列只展示真实任务数、状态、字符数和耗时，不显示虚假百分比。

## 设计方向

绘钥采用“Apple 原生极简数字暗房”风格：内容优先、舒适专业密度、低边框噪声和接近 macOS 专业创作工具的交互反馈。Arco Design 提供控件基础，品牌层只覆盖语义 Token 和领域组件外观。

## 色彩与表面

- `--bg`：应用背景。
- `--chrome`：标题栏和状态栏材质。
- `--surface`、`--surface-2`、`--surface-3`：逐级内容表面。
- `--brand`：选择、焦点和主要操作；避免大面积填充。
- `--success`：仅表示在线、保存或完成。
- `--warning`、`--danger`：风险确认和不可恢复操作。
- `--border`：弱分隔；仅在需要建立结构时使用。

明暗主题只改变颜色、材质和阴影，不改变布局。主题必须同步 `data-theme`、`color-scheme`、`body[arco-theme]` 和 Tauri 原生窗口主题。

## 尺寸与层级

- 顶部命令栏 52px，底部状态栏 30px；空指标不使用 `--` 占位。
- 宽屏项目任务栏默认 272px，可调范围 240–336px；小于 1240px 时进入 Drawer。
- 主工作区视觉输入默认占 52%，可调范围 42%–64%；结果区内部默认约 42% 摄影测定、58% 提示词。
- 圆角不超过 8px，常规工具按钮保持稳定的 32–36px 点击尺寸。
- 正文为 12–13px，辅助信息不低于 10–11px；不使用负字距。
- 正文使用系统字体；日志、请求 ID 和异常结构使用等宽字体。
- 页面用留白和弱分隔建立层级；同一区域不叠加描边、阴影和卡片背景。图片画布与提示词正文始终优先获得空间。

## 组件原则

- 命令使用按钮，模式使用 Radio 或 Tabs，数值使用 Slider/InputNumber，危险操作使用 Popconfirm。
- 图标按钮必须提供 Tooltip 和可访问名称。
- 面板不能嵌套装饰性卡片；固定工具栏和正文滚动区必须明确分离。
- 空、加载、流式、错误、禁用和只读状态使用统一语义，不依赖 Toast 才能理解。
- 设置和日志通过顶部命令栏返回工作台，内容区不重复放置第二个返回按钮。
- 设置页当前分类使用持续可见的选中状态；日志筛选与日志操作分组排列，窄屏时允许换成两行稳定工具栏。
- Drawer、Modal、Popconfirm 和 Message 共用相同表面、圆角、焦点与危险色，不为单个页面创建独立弹层风格。

## 动效

- 状态切换使用 120–180ms 的 `opacity`、`transform` 或颜色变化。
- 等待阶段允许 1.2–1.8s 的低对比扫描和呼吸动画，但必须由真实请求状态驱动。
- `prefers-reduced-motion` 下关闭循环和位移动画，保留文字、耗时和进度事实。
