# 专业精修操作说明

专业精修用于在保留模型基础结果的前提下，校正摄影测定并派生可追溯的提示词版本。基础结果始终只读，人工校正、AI 重测、提示词编辑和平台优化都会创建统一修订。

## 修订模型

- 统一修订栏显示当前修订名称、来源和提示词同步状态，并提供切换、比较和更多操作。
- 每个任务最多保存 12 个派生修订。达到上限时必须先删除旧修订，应用不会自动淘汰。
- 旧提示词版本在首次创建统一修订时幂等迁移，原始结果不会被覆盖。
- 删除入口位于统一修订栏的“更多”菜单。删除来源修订会同时影响其后续派生修订，确认框会明确显示影响数量。

## 人工校正

1. 在摄影测定标题栏点击“校正”。
2. 按画面、光影和成像分组修改十项测定或色板。
3. 修改过的字段会自动锁定，也可以手动解锁。
4. 先保存本地草稿，再按需同步提示词。

结果面板顶部的“全部 / 画面 / 光影 / 成像”分段导航用于快速定位测定组，当前分组会持续高亮；它只改变阅读位置，不修改或筛选测定内容。

本地草稿不需要 API Key。同步失败不会丢失草稿，错误区会提供重试、关联日志和诊断导出。

## EXIF 与 AI 重测

- “采用实拍参数”只使用 EXIF 白名单中的相机、镜头和曝光信息，写入镜头成像后自动锁定。
- GPS、设备序列号、作者、版权和用户备注不会进入界面、历史、日志或模型请求。
- AI 重测需要已保留原图和有效 API Key，可附加最多 500 字要求。
- 重测发送最长边 2048px 的请求图，只更新未锁定字段；停止或失败不会覆盖当前结果。

## 提示词同步与编辑

- “同步提示词”根据当前摄影测定创建派生修订，不修改基础结果。
- “编辑副本”允许修改中文、英文以及 SDXL 负面提示词。
- 平台优化支持通用、Midjourney、Flux 和 SDXL，结果仍进入同一修订链。
- 流式停止或断流时可以复制已接收的部分提示词，但不会创建正式修订。

## 比较与导出

- 比较抽屉通过“摄影测定 / 提示词”页签并排展示来源与目标修订。
- 复制完整结果以及 Markdown、Schema 2 JSON、纯文本和批量 ZIP 导出均使用当前活动修订。
- 导出包含原图时，解密后的图片会以未加密形式写出，应只选择可信位置。

## 能力限制

| 状态 | 可用操作 | 受限操作 |
| --- | --- | --- |
| 无 API Key | 人工校正、保存草稿、比较、复制 | AI 重测、提示词同步和平台优化 |
| 无原图 | 人工校正、提示词编辑、比较、导出结果 | AI 重测、导出原图 |
| 流式部分结果 | 复制已接收提示词、停止请求 | 保存正式修订、复制完整结果、正式导出 |
| 修订达到 12 个 | 查看、比较、导出、删除 | 新建派生修订 |
