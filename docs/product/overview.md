# 产品与使用说明

## 定位

绘钥面向设计师、摄影师和内容创作者，将单张参考图片转化为可复用的摄影测定结果和中英文生图提示词。应用强调本地数据控制、真实流式反馈和可排查性，不提供账号、云同步或内置生图。

## 核心流程

1. 点击、拖入或使用 `Cmd+V` 导入 PNG、JPEG、WebP 图片。
2. 在视觉输入面板配置补充要求、输出语言和详细程度。
3. 点击“开始反推”，查看摄影测定与双语提示词的真实流式输出。
4. 对提示词创建手工副本或按通用、Midjourney、Flux、SDXL 进行二次优化。
5. 复制当前提示词或完整结果，导出 Markdown、JSON、纯文本或原图。
6. 从历史恢复结果和原图；使用运行日志、关联请求和脱敏诊断排查失败。

## 数据保留

- 历史最多保留 50 条，浏览器开发模式仅保存结果和缩略图。
- 桌面应用可保存加密原图；删除历史后相应原图永久删除。
- 关闭自动保存时，生成结果只保留在当前会话，用户可手动保存。
- 旧记录没有原图时仍可查看和复制结果，但重新反推需要重新选择图片。

## 主要快捷键

| 场景 | 快捷键 |
| --- | --- |
| 生成或停止 | `Cmd/Ctrl+Enter` |
| 粘贴剪贴板图片 | `Cmd+V` |
| 停止当前请求 | `Esc` |
| 打开图片查看器 | 图片聚焦后 `Enter` 或双击 |
| 图片缩放 | `+`、`-`、触控板捏合 |
| 图片复位 | `0` |
| 平移长图 | 拖动、触控板平移或方向键 |
| 恢复结果自动分隔 | 分隔条双击、`Home` 或 `Enter` |

## 模型兼容性

模型服务必须兼容 `{Base URL}/chat/completions`，图片请求需支持 `image_url` Data URL。绘钥优先使用 SSE 和 `stream_options.include_usage`，不兼容时依次重试普通流式和非流式响应；兼容回退不会伪造逐字动画。
