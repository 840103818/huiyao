# 产品与使用说明

## 定位

绘钥面向设计师、摄影师和内容创作者，将参考图片转化为可复用的摄影测定结果和中英文生图提示词。2.0 以本地项目组织批处理和专业单图精修，强调数据控制、真实流式反馈和可排查性，不提供账号、云同步或内置生图。

## 核心流程

1. 创建或选择项目，选择入队预设。
2. 点击、拖入或使用 `Cmd+V` 导入 PNG、JPEG、WebP；批量导入最多 100 张和 1 GB。
3. 启动队列，查看摄影测定与双语提示词的真实流式输出。
4. 在统一修订栏校正摄影测定；修改字段自动锁定，AI 重测只更新未锁定字段。
5. 保存本地校正草稿并同步提示词，或创建提示词编辑副本及通用、Midjourney、Flux、SDXL 平台优化修订。
6. 比较修订的摄影测定与提示词，复制当前结果并导出 Markdown、Schema 2 JSON、纯文本或原图。
7. 通过收藏、标签、重命名、单项重试和状态筛选管理任务，使用废纸篓恢复误删内容。
8. 使用运行日志、关联请求和脱敏诊断排查失败。

## 数据保留

- 项目任务存入私有 SQLite 数据库，列表每次加载 50 条。
- 桌面应用在任务导入时加密归档原图，默认软配额为 10 GB。
- 项目和任务删除后进入废纸篓，保留 30 天。
- 旧历史迁入“历史记录”项目；没有原图的旧任务仍可查看和复制结果。

## 主要快捷键

| 场景 | 快捷键 |
| --- | --- |
| 生成或停止 | `Cmd/Ctrl+Enter` |
| 打开快捷命令 | `Cmd+K` |
| 粘贴剪贴板图片 | `Cmd+V` |
| 停止当前请求 | `Esc` |
| 打开图片查看器 | 图片聚焦后 `Enter` 或双击 |
| 图片缩放 | `+`、`-`、触控板捏合；`100%` 表示原始像素 `1:1` |
| 适应窗口 / 实际大小 / 适应宽度 | `0` / `1` / `2` |
| 平移长图 | 拖动、触控板平移或方向键；`Shift+方向键` 加速 |
| 恢复结果自动分隔 | 分隔条双击、`Home` 或 `Enter` |

## 模型兼容性

模型服务必须兼容 `{Base URL}/chat/completions`，图片请求需支持 `image_url` Data URL。绘钥优先使用 SSE 和 `stream_options.include_usage`，不兼容时依次重试普通流式和非流式响应；兼容回退不会伪造逐字动画。

## 原生界面语言

macOS 应用包以简体中文声明原生界面语言。WebView 进程异常时由系统提供的恢复按钮显示“重新载入”，与应用内中文界面保持一致。

## 图片沉浸查看

图片查看器默认以“适应窗口”打开，顶部文件信息和底部检查工具在无操作 1.8 秒后自动淡出，移动指针、滚动或按键即可恢复。放大后右下角按需显示位置导航，可点击或拖动视口框快速定位长图；关闭查看器使用右上角按钮或 `Esc`，背景点击不会误关闭。
