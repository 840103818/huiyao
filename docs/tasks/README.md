# 历史实施记录

本目录保留绘钥接入 OpenSpec 之前的重要实施记录，用于追踪版本背景和当时的验证证据。原文件和路径继续保留，但不再作为当前行为规范，也不再为新任务创建同类目录。

从 OpenSpec `1.7.0` 接入开始：

- 当前稳定行为维护在 [`openspec/specs/`](../../openspec/specs/)。
- 新的复杂变更维护在 [`openspec/changes/`](../../openspec/changes/)。
- 完成的变更由 OpenSpec 归档到 `openspec/changes/archive/`。
- 用户说明、架构、ADR、测试、发布和视觉基线继续维护在对应 `docs/` 目录。
