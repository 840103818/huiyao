# 2.0 专业精修实施记录

## 目标

- 保持 Apple 数字暗房三栏工作台和现有安全边界。
- 统一人工校正、AI 重测、提示词编辑和平台优化的结果版本模型。
- 提升单项任务整理、批量收藏/标签和完整预设编辑能力。
- 版本升级至 `2.0.0`，不修改 SQLite Schema、原图格式或模型服务配置模式。

## 实施

- 新增 `ResultRevision` 跨端契约、统一修订栏、校正与比较 Drawer。
- 人工字段修改自动锁定；EXIF 可写入镜头成像；AI 重测只更新未锁定字段，并在 Rust 返回前再次恢复锁定内容。
- 本地草稿与提示词同步分离；失败状态保留草稿，并关联日志与脱敏诊断入口。
- 旧 `promptVersions` 在首次创建派生修订时转换；每个任务最多 12 个派生修订。
- 任务菜单增加重命名和单项重试；批量操作增加收藏和标签；预设编辑覆盖完整快照。
- 结构化导出升级到 `schemaVersion: 2`，所有格式使用当前活动修订。
